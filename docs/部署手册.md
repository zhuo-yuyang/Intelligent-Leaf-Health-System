# 智能植物叶片健康监测系统 部署手册

> 课题A ｜ 第3组 ｜ 卓玉阳 / 陈炜 / 张佳明 ｜ 平台：树莓派 5（Raspberry Pi OS Bookworm 64-bit）

## 一、硬件准备

| 部件 | 规格 | 数量 |
|:---|:---|:---|
| 树莓派开发板 | Raspberry Pi 5 4GB | 1 |
| CSI 摄像头 | OV5647 500 万像素，15 针 FPC 排线接 J4 | 1 |
| 触摸显示屏 | MHS-3.5inch，SPI 接口，ILI9486，横屏 | 1 |
| 电源适配器 | 5V/5A USB-C | 1 |
| MicroSD 卡 | 32GB 以上 Class 10 | 1 |

摄像头排线金属触点朝向网口方向，插到底后按下锁扣；屏幕直接扣在 40Pin GPIO 上。

## 二、操作系统安装

1. 用 Raspberry Pi Imager 烧录 `Raspberry Pi OS (64-bit) — Bookworm`。
2. 齿轮（高级配置）中设置：主机名 `pi5-group3`、用户名 `pi`、Wi-Fi、时区 `Asia/Shanghai`，
   并在 Services 页勾选 **Enable SSH → Use password authentication**。
3. 首启后确认桌面正常显示，记录 IP：

```bash
hostname -I          # 本组为 10.201.4.192
```

## 三、屏幕与摄像头

```bash
# 屏幕：LCD-show 驱动（Bookworm 下用 MHS35 脚本）
git clone https://github.com/goodtft/LCD-show.git
cd LCD-show && chmod -R 755 LCD-show && sudo ./MHS35-show
sudo ./rotate.sh 90          # 横屏

# 摄像头：先确认自动识别
rpicam-hello --list-cameras  # 应列出 ov5647
rpicam-hello -t 0            # 预览 5 秒，Ctrl+C 退出
```

若报 `no cameras available`：编辑 `/boot/firmware/config.txt`，设 `camera_auto_detect=0`
并在末尾加 `dtoverlay=ov5647`，重启后再验证。

## 四、软件环境

```bash
sudo apt update
sudo apt install -y python3-picamera2 python3-libcamera libcamera-apps sqlite3

cd ~/smart_system
python3 -m venv --system-site-packages venv   # 必须带 system-site-packages 才能用 picamera2
source venv/bin/activate

pip install opencv-python flask numpy
pip install tflite-runtime                    # 或 tensorflow（体积大，不推荐）
```

> 注意：`ai_module_leaf.py` 中默认写的是
> `from tensorflow.lite.python import interpreter as tflite`。
> 若只装了 `tflite-runtime`，需改成
> `import tflite_runtime.interpreter as tflite`（文件中已留注释行）。

## 五、项目部署

```bash
# 1. 拷贝代码
scp -r flask_app docs ~/smart_system/          # 或在 VS Code Remote-SSH 中直接拖拽

# 2. 确认关键文件
cd ~/smart_system/flask_app
ls main.py app.py camera_manager.py vision_module.py ai_module_leaf.py \
   db_helper.py db_init.py leaf_model.tflite templates/ static/

# 3. 初始化数据库
python db_init.py

# 4. 前台试运行
python main.py            # 看到 "Web 服务启动" 即成功，Ctrl+C 退出
```

## 六、配置开机自启动（Systemd）

```bash
sudo cp ~/smart_system/smart_system.service /etc/systemd/system/smart_system.service
sudo systemctl daemon-reload
sudo systemctl enable smart_system
sudo systemctl start smart_system
sudo systemctl status smart_system        # 期望 active (running)
```

服务文件要点：

```ini
[Service]
Type=simple
User=pi
WorkingDirectory=/home/pi/smart_system/flask_app
ExecStart=/home/pi/smart_system/venv/bin/python /home/pi/smart_system/flask_app/main.py
Restart=always          # 崩溃后 10 秒自动拉起
RestartSec=10
```

`ExecStart` 必须写虚拟环境里的 python 绝对路径，否则会缺少 opencv-python 等依赖。

## 八、常见问题

| 问题 | 原因 | 解决方法 |
|:---|:---|:---|
| 服务起不来，日志报 `No module named 'picamera2'` | venv 未带 `--system-site-packages` | 重建 venv 或 `pip install picamera2` |
| 服务反复重启 | 摄像头被占用 / 端口被占 | `sudo lsof -i:5000`，停掉手动跑的 `app.py` |
| 视频流只有第一帧、之后卡住 | 多标签页同时拉流抢队列 | 只留一个客户端，或改用共享最新帧 |
| `/api/stop` 后画面仍在检测 | 采集线程未读取 `detection_enabled` | 见《问题与解决》，属已知待优化项 |
| `detections.db` 迅速撑到几 GB | `detail_info` 存了整幅 mask 数组 | 只存 `disease_ratio` 等标量，并 `VACUUM` 收缩 |
| 数据库为空 | 未初始化 / 服务未运行 | `python db_init.py`，确认服务 active |

数据库清理（实测 2394 条记录膨胀到约 4.3GB 后使用）：

```bash
cd ~/smart_system
sqlite3 detections.db "DELETE FROM detections WHERE id NOT IN (SELECT id FROM detections ORDER BY id DESC LIMIT 500);"
sqlite3 detections.db "VACUUM;"
```
